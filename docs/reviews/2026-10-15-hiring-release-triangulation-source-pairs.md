## Prospective analysis contract, not executed

- **Index:** employer + official requisition ID where genuinely present, not a title or scraped URL; retain exact observation timestamp, source granularity and reviewer state. A currently readable job URL has **unknown first-posted UTC unless explicitly shown**, so these October observations cannot be used to predict past April–September releases.
- **Event:** company + product + canonical URL + original published date + independently checked event/rollout date (nullable) + availability status. Company newsroom, job and own benchmark are correlated first-party material, **not three independent confirmations**.
- **Prospective frame only:** select employers, roles, query channels, date cutoff, releases and matched control firms **before** new observations; keep all failed queries and disappearing jobs. Predeclare release-only baseline versus prior-job-signal classifier and company-shuffled negative control. Compute denominators by accessible tracked requisitions and reachable dated release events, not total company hiring.
- **Falsify predictions:** no new externally accessible feature during the prespecified horizon, regression after release, inability to reproduce independent accepted tasks, incompatibility/maintenance cost, or identification mismatch. Report missing and null pairs, no post-hoc cherry-picking.
- **Task experiments:** for each corresponding theme use **independently specified functional acceptance**, task-level assignment/abstentions and quality/security gates; record reused component/version, denied actions, failed attempts, human review, retrieval costs and 30/90-day upkeep. Approved opt-in access and reproducible provider telemetry are prerequisites to any causal productivity or energy/carbon finding.
- **Access, privacy, sampling:** no site crawling, job-applicant data, salary/headcount extrapolation, copied job descriptions or claims of actual filled vacancies. Source links may change; direct re-open is a time-bounded check. Human factual/rights and scientific methods review is pending. This matrix is **E0/E1 documentary triangulation**, not an E3 validated useful-reuse study.

## One practical repo lesson

Treat advertised agent reliability as a **testable hypothesis**. For each own repository, publish a pinned, clean-room functional task and rights/security smoke check, preserve all abandoned attempts and maintenance costs, and solicit an **independent opt-in user** to reproduce it. If the tool increases review effort or fails a safety boundary, keep the existing simpler implementation. Never infer energy savings from fewer model tokens.
