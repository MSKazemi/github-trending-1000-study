## First quarter 2027: validate ONE real useful workflow before expansion
- Collect a documented task sample independently of any agent or preexisting reuse success; include cases likely to have and not to have viable software. Pilot target size is **to be determined** by review capacity and statistical precision.
- Compare at least conventional GitHub/package discovery against structured reuse-first prompts using blind task-to-component judgments. Keep time, token and package/security review overhead, unknown candidate pairs, and failures.
- Run limited independent user-task trials with proper consent, and estimate effect-size uncertainty. Don't treat source-code clone frequency as waste itself.
- Test whether the new evidence-based workflow helps in one narrowly scoped language/project type; accept neutral or negative findings.
- Only then decide whether multi-agent reproducibility and a larger randomized experiment are feasible.

## First advisory review: proposed questions
- What would falsify the central reuse-first thesis? Have we preserved null results?
- Do external reviewers agree on viability and user-task success, or is 'useful' subjective?
- Can any public-repo agent-use label be trusted, and where does hidden usage contaminate controls?
- Are old/low-star projects discoverable under our retrieval frame, including non-English and non-GitHub hosting?
- Does the proposed reused dependency meet legal, security, upgrade and maintainer burden constraints?
- Can electricity/environmental impacts be measured or defensibly bounded for identical functional workloads?
- Which planned workstream creates evidence rather than another unvalidated software tool?

## Deliverable control
The first publishable research result can be a **methodological negative finding**: for example, that a widely used popularity metric has poor predictive validity for a precisely defined independent task-success benchmark. This is valuable if reproducible, accurately scoped and preregistered where needed. It is not necessary to launch a discovery platform or achieve 1,000 observations to begin independent pilot science, but a **final** claims study must report the actual sample and revised objective transparently.
