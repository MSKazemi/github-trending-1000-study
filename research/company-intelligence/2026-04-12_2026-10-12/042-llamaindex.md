## 8. One falsifiable reuse-first maintainer experiment (proposed; not executed)

**Target:** [github-trending-1000-study](https://github.com/MSKazemi/github-trending-1000-study) documentation (`docs/`, `research/`), used offline. No live GitHub Trending capture is involved; `capture` stays **disabled** under the source-access decision.

**Task (functional unit):** given a natural-language question about the study protocol (e.g. "where is the rule that unknown measures must not become 0?"), return the file and section that answers it. Before any run, a human who is **not** the agent operator freezes 40 questions with gold file/section labels, including **8 deliberate no-answer questions**. All 40 stay in the denominator.

**Comparator A (existing tools):** `ripgrep` keyword search plus a 30-line ranking script, i.e. what the maintainer already has. **Treatment B (reuse):** `llama-index-core` pinned at the exact in-window release (v0.14.25, MIT) with a **local** embedding model and in-memory `VectorStoreIndex` plus a BM25 hybrid (the BM25 retriever is a separate integration package and must be pinned and reviewed too). No LlamaCloud/LlamaParse account, no hosted index, no paid LLM API. **Optional C:** B plus a grep/read tool loop, mirroring the vendor's Retrieval Harness idea with OSS parts only.

**Primary endpoint:** gold section in top-5 across all 40 questions; for no-answer questions, success means "no confident match". **Secondary:** setup and 30-day maintenance minutes (human, logged), added dependency count and install size, known-vulnerability count of the pinned dependency tree at install, CI wall-clock, and breakage after one upstream minor upgrade. Energy is reported only if actually metered.

**Guardrails:** dependency/licence review **before** install (per AGENTS.md); no private data or credentials; the hidden question set is never shown to the agent that builds B/C.

**Stop rule:** keep A if B/C does not beat A by **≥10 percentage points** top-5 on the frozen set. Also keep A if B/C adds an unresolved high-severity advisory, an unclear licence, or more than 2× A's setup-plus-maintenance minutes. A null result ("grep is enough for this corpus") is a valid finding and must be preserved. **No trial executed, no effect estimated.**
