## 8. One falsifiable reuse-first maintainer experiment

**Target:** an authorized, isolated sandbox copy of a small analysis task from [github-trending-1000-study](https://github.com/MSKazemi/github-trending-1000-study). Use offline synthetic fixtures only. The study's live Trending `capture` stays **disabled**, and no framework changes that.

**Frozen task (preregister before running):** given a committed synthetic parsed-Trending JSONL fixture, produce a per-language summary table plus a one-paragraph caveat note. Define 20 task instances: 14 solvable, 3 with deliberately malformed rows that must be flagged rather than dropped, and 3 with no valid answer that must be refused. All 20 count in the denominator. Hidden acceptance assertions are authored by a human independent of the agent configuration and kept out of agent context.

**Comparators:** **A (reuse-first baseline):** the existing repository code path plus one single LLM call, or none if the code path suffices. **B:** a pinned `crewai==1.15.24` crew/flow (e.g. a parser-check agent, a summarizer agent and a reviewer agent) using the same model, temperature and tool permissions, with tool-result caching left at its documented default and recorded. Both arms run offline with no network tools, which rules out SSRF classes.

**Primary endpoint:** independently accepted instances divided by **all 20 assigned instances**, with failures, `max_iter` stalls, refusals and timeouts counted as not accepted. **Secondary endpoints:** total tokens, wall-clock latency, number of LLM calls (coordination overhead), maintainer setup and review minutes, dependency count and known-CVE count at the pinned version, and metered energy *only if instrumented*.

**Cost bound:** ≤ 4 human hours and a fixed token budget agreed before running (e.g. 2× the arm-A token use per instance). Stop arm B if the budget is exceeded.

**Stop/reversal rule:** prefer A if B is not **strictly better** on accepted instances, or if B uses more than 1.5× A's tokens for equal acceptance. Stop immediately on any network egress, credential read, silently dropped malformed row, or unresolved High CVE in the pinned dependency set. A null or negative result is a valid outcome and must be preserved. **No trial has been executed and no effects are estimated.**
