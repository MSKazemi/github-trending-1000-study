Provisional screen; the issue may be closed with this status recorded, and human factual/link, rights and methods review gates remain open. News corpus: [#56](https://github.com/MSKazemi/github-trending-1000-study/issues/56).

**Window:** 2026-04-12…2026-10-12 inclusive (UTC dates). **Accessed:** 2026-10-16. **Method:** raw-HTML retrieval with `curl` (generic `Mozilla/5.0` User-Agent, except the two hosts noted below where robots.txt explicitly allows `Claude-User`; no personal identifier, email or credential sent to any site), local text extraction and regex `grep` of saved text to confirm numbers, versions, dates and quotes; `gh api` for JetBrains GitHub repositories and releases; the Hugging Face model API and raw model cards; the NVD CVE API for five CVE records; the Hacker News Algolia API for discovery of independent coverage. WebSearch/WebFetch were **not** used. **This is not exhaustive retrieval.** Search-engine result totals were not available and are recorded as unknown, not zero. No page snapshots or hashes were archived in the repository; vendor pages and the SWE-rebench leaderboard are mutable.

## Inclusion, deduplication and conflicts

- **Included:** see the report's *Standardisation upgrade* section for the final row count and per-segment counts. Every row cites a URL that was fetched as raw text or queried by API; no row relies on a search snippet alone. Three security-bulletin rows cite the same client-rendered bulletin page, whose data were read from the JSON feed behind it.
- **Duplicate groups:** `017-MODELS` (model-support releases), `017-GA` (GA post and SWE-rebench leaderboard), `017-LOCAL` (MLX models, Junie Local launch, Techstrong report, blend update), `017-DEMO` (CLI release and blog post), `017-PRICING` (Gemini promotions, session cost, Junie Lite), `017-SEC-AGENT` (agent/MCP security bulletins and the Junie trust gate), `017-KOOG`, `017-REVIEW`, `017-AIR`, `017-TOKENS`, `017-PLUGINSEC`, `017-TEAMCITY`, `017-PERF`, `017-THINKRAIL`, `017-EXT`, `017-AUTONOMY`.
- **Date conflicts recorded, not resolved:** /demo shipped in CLI 26.8.31 on Aug 31 but was announced on Sep 17; Junie Lite shipped in CLI on Oct 1, blog Oct 2; the Junie Local launch post also exists at `blog.jetbrains.com/junie/2026/08/junie-local-launch/` (same date); the blend-model Hugging Face repos were created Sep 15, three days before the Sep 18 post; Mellum2 Hugging Face repos were created May 26 while the open-source post appeared on Jun 1 (HN first seen Jun 1); the user critique page has no date (HN submission used); the annual-highlights page has no date (team-blog URL path used); benjamin-plus has only a repository creation date.
- **Figure conflicts recorded:** Junie Local download "about 20 GB" (launch post) vs "~40 GB (for the model download)" (product page, which also says "About 20 GB of model weights"); SWE-rebench 61.6% / 72.7% (vendor quote, Jun 17) vs 61.8% / 73.9% (leaderboard default view on Oct 16, window May 15–Jul 1); CVSS for CVE-2026-41153 5.8 (JetBrains CNA) vs 9.8 (NVD), CVE-2026-57922 3.1 vs 5.3, CVE-2026-100265 4.8 vs 6.5; "Agent Communication Protocol" (Junie GA post) vs "Agent Client Protocol" (Air post, annual highlights); Mellum called "proprietary" (annual highlights) vs Apache-2.0 model cards; Junie Lite "isn't a trial, and there's no countdown*" vs footnote "Offer is valid until 31 Dec 2026".
- **Licence observation:** the public `JetBrains/junie` GitHub repository (release binaries) carries `LICENSE.md` "© JetBrains s.r.o. All rights reserved. Use is subject to JetBrains AI Service Terms of Service"; the GitHub API licence field is `NOASSERTION`. Koog, ThinkRail, Roer and Kotlin toolchain are Apache-2.0; benjamin-plus is MIT; `JetBrains/context` has no licence field.
- **Figures confirmed against raw saved text or API JSON:** all Junie release dates, tags and feature lines quoted in rows; Koog 1.0.0 / 1.2.0 / 1.3.0 notes; Kotlin 2.4.0 and 2.4.x dates; kotlin-toolchain first release and Amper README text; 151 / 13 / 54 / 62 / 22 bulletin counts and the six ledgered bulletin entries; the five NVD records (publication timestamps, CNA and NVD CVSS vectors); Hugging Face creation dates and licence tags; Mellum2 MoE 64 experts / 8 active / 131,072 context; Mellum2.1 12B total / 2.5B active, SWE-bench Verified 47.0 vs 2.0 (Mellum2 Thinking) vs 50.0 (Qwen3.5 9B), Terminal-Bench 2.1 17.4, values "self-reported by JetBrains"; Junie Local Qwen3.6-27B 4-bit, ~20 GB, M5 / 64 GB, free; blend 37 vs 34 vs 39 of 100 tasks, 71% fewer output tokens, LiveCodeBench 85.47% vs 83.29%, RTX Ampere+ ≥24 GB; Junie Lite Qwen 3.6 27B, 31 Dec 2026; Gemini 3.8 Flash 75% off; Aikido 15 plugins / seven vendor accounts / plain HTTP / earliest Oct 2025; Techstrong $4,499; SWE-rebench values; Junie GA post 61.6% / 72.7%, `.junie/plans`; benjamin-plus −18% / −22% / ~745 tokens; annual highlights "six-figure", +101.33%. All remain **vendor or third-party statements**, not verified measurements.
- **Not confirmed:** whether JetBrains removed the plugins named by Aikido; exploitation status of any CVE; whether Air Teams or Air Governance are generally available; the Amper archival date; JetBrains revenue/loss figures (source robots-disallowed).
- **Untrusted-content note:** fetched pages were treated as data. The ThinkRail blog and repository suggest piping a remote install script into a shell (`curl … | bash`, `irm … | iex`); nothing was executed. The Aikido post quotes malicious plugin code as an example. A regex scan of saved text for agent-directed instructions (e.g. "ignore previous instructions", "AI agent", "assistant") found none addressed to this researcher. The devclass.com/theregister.com robots.txt contains comments describing Anthropic user agents; they were treated as access rules only.
