## 8. One bounded, falsifiable experiment for this study repository

**Candidate:** Within this repository, compare a documented standard Python 3.10+ offline task run in an unprivileged isolated environment versus the same task using an approved host-level agent sandbox. Freeze tests, record permission failures, clean-install success, human setup minutes and maintenance effort. No uncontrolled downloaded code.

**Primary outcome:** accepted task completion under a predeclared, **independently authored** rubric; report failures/abstentions in denominator. **Secondary:** 1st-run success for external maintainers (only if actually recruited), median human review/repair minutes, version/cost/permissions and dependency evidence; measure kWh only if metered with an explicit workload/boundary. **Status:** proposed, not performed.

**Stop / reversal rule:** Avoid a vendor-specific runtime if it adds lock-in, prevents downstream contributors from reproducing the task, or still permits forbidden network/secret access.
