**Window:** 2026-04-12…2026-10-12 inclusive (UTC dates). **Accessed:** 2026-10-16. **Method:** `robots.txt` checked first for every host fetched; raw HTML retrieved with `curl` using a generic `Mozilla/5.0` User-Agent (no personal identifier, email, account or credential sent to any site); visible text extracted locally and every number, version, date and quote used in the ledger confirmed by `grep` of the saved raw text (qualified by the 2026-10-16 spot-check, which found one wrong limitation and two wording errors among 26 rows checked); `gh api` for GitHub repositories, releases and advisories; OSV.dev JSON API for malware records; Hacker News Algolia API plus the HN HTML item page; four public web searches (WebSearch tool) used for leads only. **This is not exhaustive retrieval.** Search-engine result totals were not exposed and are recorded as unknown, not zero.
