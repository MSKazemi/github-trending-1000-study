**Window:** 2026-04-12…2026-10-12 inclusive. **Research/source inspection:** 2026-10-16.

**Provenance.** Sources came from public web search (WebSearch tool, provider-interpreted queries) and from direct reads of official pages:
- the [Help Center product-updates index](https://help.zapier.com/hc/en-us/categories/13951101412877-Product-updates) and individual articles;

- [SDK docs](https://docs.zapier.com/sdk) and the [AutomationBench leaderboard](https://zapier.com/benchmarks).

Public, unauthenticated metadata endpoints were also read:
- the Zendesk Help Center article API (`https://help.zapier.com/api/v2/help_center/en-us/articles/<id>.json`), for `created_at`/`edited_at`, because the Help Center pages show no per-article date;
- the public npm registry (`https://registry.npmjs.org/<package>`), for version publish timestamps;
- the GitHub REST API (`gh api`), for public repository metadata, license files and commit dates in the `zapier` organization.

Each relevant dated event is one row in [048-zapier.events.csv](048-zapier.events.csv). **This is not exhaustive internet discovery.** Search result totals, query-run UTC times and complete excluded-hit denominators are unavailable, not zero. Snapshot hashes of third-party websites were not obtained.

### Inclusion, exclusion and data validity decisions

- **Included = 25 ledger rows** (Apr 5, May 9, Jun 2, Jul 4, Aug 2, Sep 2, Oct 1–12 1). Four rows share the `048-automationbench` group: one benchmark program with several dated records and **conflicting metrics**. They are not independent confirmations.
- **Date semantics:**
  - Help Center rows use the article API `created_at`. Visible pages carry no date, and public-visibility timing may differ.
  - GitHub rows use repository `created_at`, which is **not** an announcement date.
  - Developer Platform rows use the release date shown on the page.
  - The Token Security row separates in-window publication (May 28) from the pre-window underlying report (Feb 12).
- **Availability classes:**
  - Preview: SDK (open beta), connectors (prototype), Next Gen Zaps (early access).
  - Announced only: Functions retirement and the three upstream deprecation notices.
  - Corrected: security research disclosure, AutomationBench 1.0.6 task fixes, v19.2.0 credential-handling fixes.
  - Reported, undetermined: partner benchmark run, CEO statement.
  - Do not upgrade early access or beta to GA.
- **Primary vs independent:** No neutral E3 evidence was found for any feature. Artificial Analysis is a declared partner. Create With, Collab365 and AI PICKS restate other sources. Token Security is an external researcher (second entity), but its account is not independently replicated.
- **Months with weak coverage:** August and October 1–12 have no surfaced first-party feature launch. This is **unknown, not zero activity**: monthly "updated integrations" roundups exist but were not itemized.
- **Review access:** public pages and public metadata APIs only. No login, paywall bypass, private repository, exploitation or personal data. No github.com/trending access. Public pages may change. Factual and scientific **independent human review is pending**.

The search screen is a reproducible **lead inventory**, not a systematic review. A future reviewer should re-run these queries, record result totals with UTC timestamps, confirm Help Center publication visibility dates, locate the primary Zapier AutomationBench and SDK launch posts, and itemize the monthly integration roundups before any issue closure.
