## 2. Verified company/product identity and baseline

Hugging Face runs the Hub (hosting of models, datasets, Spaces apps, Storage Buckets and, from April, Kernels repositories), paid compute (Inference Endpoints, Jobs, Spaces hardware), the Inference Providers router to third-party providers, and Team/Enterprise plans. Its open-source libraries are mostly Apache-2.0 per GitHub API (transformers, huggingface_hub, datasets, diffusers, smolagents, lerobot, kernels, tokenizers, sentence-transformers, xet-core, funes); OpenEnv is BSD-3-Clause; hf-discover is MIT; **transformers-to-mlx has no detected licence**. The Hub service itself is proprietary and hosted.

Pre-window baseline (context only): text-generation-inference is **archived** on GitHub (last push 2026-03-21); EvalEval's Every Eval Ever and HF Community Evals both launched in February 2026 ([HF blog](https://huggingface.co/blog/eee-community-evals)). The HF Hub stated growth Jan–Aug 2026 from 2.43M to 2.96M public model repositories ([State of Open Models](https://huggingface.co/blog/state-of-open-models-summer-2026)); NVIDIA's announcement says "more than 3 million models". The two figures use different dates and definitions and are not treated as a conflict.

## 8. One practical, falsifiable change for the maintainer's own repositories

**Repository/component:** [github-trending-1000-study](https://github.com/MSKazemi/github-trending-1000-study), its offline synthetic fixtures and unit tests (`python -m unittest discover -s tests -v`). No network capture; the disabled Trending `capture` command stays disabled.

**Candidate practice (not yet validated):** publish one **synthetic** fixture bundle (for example the committed goldset and idea-card examples) as a versioned Hugging Face dataset with a dataset card, an explicit licence, a pinned revision, and upload done from CI through Trusted Publishers (OIDC) with a contributor-scoped token, instead of only keeping it inside the Git repository. Reuse first: use `huggingface_hub` (Apache-2.0, pinned exact version) and the existing GitHub Actions workflow; build no new uploader.

**Treatment/control and frozen comparable task:** Freeze one external-user task: "load the synthetic goldset at a pinned version and reproduce the `trending_study.goldset --k 2` demonstration output". Control: instructions point to the Git repository path at a pinned commit. Treatment: instructions point to the HF dataset at a pinned revision. Recruit consenting testers (not the maintainer) who attempt one arm each, in random order; acceptance is judged by a fixed expected-output file written before the trial by someone other than the person running it. Accepted-task unit: one tester run that reproduces the expected output without help.

**Success and guardrails:** Primary: accepted runs / all assigned runs (including abandoned). Guardrails: no real Trending data, personal data or secrets in the published bundle; dataset card states it is synthetic; licence matches the repository; CI holds no long-lived HF token (OIDC only); full unit suite green; no paid API spend without approval. Measured human work: maintainer setup minutes, tester minutes to first success, support messages answered. Cost: invoice lines only if billed; no energy or CO2e estimate unless metered. Commit authorship stays with the maintainer.

**Stop/reversal rule:** Stop and keep Git-only distribution if treatment does not improve accepted-run rate, adds more than 30 maintainer setup minutes or any recurring weekly upkeep, requires a token broader than contributor scope, or if the pending change of ownership alters the Hub's terms in a way that conflicts with the study's open-data commitments. Stop immediately on any accidental publication of non-synthetic data. **No trial executed; no effect estimated.**

## 9. Findings, uncertainties and review outcome

- **Observed/shipped (documentary):** 25 transformers and 34 huggingface_hub GitHub releases in window, with PyPI upload times confirmed for cited versions; datasets 5.0.0/5.0.1; Sandboxes, Trusted Publishers, hf-cli skill auto-install, hub 1.26.0 security fixes, hub 2.0.0 breaking release; Funes (Apache-2.0) and hf-discover (MIT) repositories; 11 GitHub security advisories in window for HF packages; an agent-usage dataset created 2026-07-02.
- **Claims/announcements only:** kernel speed-ups (1.7–2.5×), token savings (up to 6×), $0.25 per release, agent user counts, ecosystem statistics, NVIDIA's neutrality commitments, OS4Science plans, ARD (draft spec).
