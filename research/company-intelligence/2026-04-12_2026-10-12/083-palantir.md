## 2. Verified company/product identity and baseline

Palantir sells proprietary, hosted (or customer-hosted) platforms: Foundry (data integration and the **Ontology**, a typed model of objects, links, actions and functions), AIP (LLM orchestration on top of the Ontology: AIP Logic, AIP Analyst, AIP Chatbot Studio, **AI FDE**, an in-platform building agent) and Apollo (continuous deployment). The developer-facing open surface is a set of client SDKs and tools: the OSDK TypeScript monorepo [palantir/osdk-ts](https://github.com/palantir/osdk-ts) (npm packages declare Apache-2.0, but the GitHub API reports **no detected licence** for the repository), [foundry-platform-python](https://github.com/palantir/foundry-platform-python) (Apache-2.0; PyPI `foundry-platform-sdk`), and [palantir/palantir-mcp](https://github.com/palantir/palantir-mcp) (MIT). The `palantir-mcp` README describes it as a "lightweight open-source wrapper for downloading and installing the @palantir/mcp package from secure Foundry environments": **the MCP server itself is not public**.

Pre-window baseline (context only, not counted): `palantir-mcp` repo created 2025-10-14 and first npm release 2025-10-15; `osdk-ts` root `CLAUDE.md` first committed 2025-08-28 and `packages/react/AGENTS.md` 2026-01-23; standalone OAuth client creation removed from Developer Console in January 2026 (stated in the 2026-05-26 announcement); Q4 2025 results 2026-02-02. **Post-window, excluded:** documentation entries dated 2026-10-13 and 2026-10-15 (branching for TypeScript v2/Python functions, Developer Console branching, new model notices) and the 2026-10-15 Customers Bank release.

## 8. One practical, falsifiable change for the maintainer's own repositories

**Repository/component:** [github-trending-1000-study](https://github.com/MSKazemi/github-trending-1000-study) offline unit-test suite (`python -m unittest discover -s tests -v`), run as a **synthetic, network-free** task set. The disabled Trending `capture` command stays disabled.

**Candidate practice (not yet validated):** Forbid coding agents from editing test files during a task and judge patches only against hidden, independently authored acceptance tests, instead of letting the agent write and iterate on its own tests until they pass (the pattern Palantir documents for AI FDE + AIP Evals). Reuse first: use the existing `unittest` suite and a simple path-based pre-commit check (or `git diff --name-only` filter) on `tests/`; build no new tooling.

**Treatment/control and frozen comparable task:** Freeze 10 small synthetic issues (validator edge cases, CSV-schema checks, CLI messages) with hidden acceptance tests written by a person other than the agent operator, kept out of agent context. Arm A (control, Palantir-style): agent may add or modify tests and iterate until its own tests pass. Arm B (treatment): agent may not touch `tests/`; it sees only the issue text and existing public tests. Same agent, model version, prompt template and time budget per arm; arm order randomized per task. Accepted-task unit: one patch that passes all hidden tests and the full existing suite and is accepted by the human reviewer without rework.

**Success and guardrails:** Primary outcome: accepted tasks / 10 assigned per arm (refused, failed, timed-out included). Secondary: "self-pass but hidden-fail" count in Arm A. Guardrails: no network access, no credentials, no new dependencies, full suite green, no edits to protocol or capture code, no paid API spend without the owner's explicit approval (use the existing subscription), and commits authored by the maintainer only, with no AI contributor attribution. Measured human work: test-writing minutes, per-task review minutes, rework minutes. No energy or carbon estimate.

**Stop/reversal rule:** Stop after the 20 attempts. Adopt Arm B only if its accepted-task rate is at least equal to Arm A's and Arm A shows at least one self-pass/hidden-fail case; otherwise record a null result and keep current practice. Stop immediately if any arm modifies hidden tests, touches the network or requires a secret. **No trial executed; no effect estimated.**
