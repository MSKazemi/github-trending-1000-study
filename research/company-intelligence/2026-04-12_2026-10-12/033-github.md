### M1–M7 connection and a maintainer-ready falsifiable pilot (not run)

**Pilot context:** a repository with small reproducible Python fixes. Freeze 8–12 independent task/fixture IDs, SHA-pinned dependencies, accepted test conditions, allowed licenses and a prespecified assignment schedule. Compare **agent tasks using separate worktrees** with the **same agent/model and budget running sequentially** where supported; counterbalance task assignment to reduce difficulty confounding. Evaluate the **all-assigned-task denominator**, including failures, interruptions, incomplete PRs, and inaccessible integrations.

**Primary unit:** independently accepted fix passing hidden tests and a human security/licensing review. **Secondary:** reviewer+repair minutes, CI re-runs, escaped defects, number of correctly reused upstream components, actual billed spend if available and support burden over 30 days. **Stop:** permission leak, unapproved auto-merge, materially worse accepted-task rate, or excessive review burden. Mapping: M1 agent workflow, M2 discovery, M3 accepted-task quality, M4 external reuse, M5 review load, M6 rights/security, M7 total lifecycle cost. Human review, source rights, energy/kWh and independent reuse remain unmeasured.
