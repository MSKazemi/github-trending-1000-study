# Google DeepMind (003): provisional source-query and inclusion log

> **PROVISIONAL, AI-ASSISTED, NOT HUMAN-REVIEWED (screened 2026-10-16).** Companion to the [report](003-google-deepmind.md) and [event ledger](003-google-deepmind.events.csv) for [#69](https://github.com/MSKazemi/github-trending-1000-study/issues/69). Provisional screen; the issue may be closed with this status recorded, and human factual/link, rights and methods review gates remain open.

**Window:** 2026-04-12 to 2026-10-12 inclusive (UTC dates). **Accessed:** 2026-10-16. **Method:** `robots.txt` checked for every host before fetching; raw HTML retrieved with `curl` using a generic `Mozilla/5.0` User-Agent (The Register fetched as `Claude-User`, which its `robots.txt` explicitly allows); text extracted locally, and every number, price, version, date and quote used in a ledger row was confirmed with a text search of the saved page or API response. Publication dates come from the page's `datePublished` metadata or the displayed date. GitHub data came from `gh api`; Hugging Face data from its public model API; PyPI data from the release RSS feed (the PyPI JSON API was not used). No personal identifier, email address or credential was sent to any site. Web search was not used (budget exhausted); discovery was direct (index pages, sitemaps, changelog, GitHub, registries) plus the Hacker News Algolia API for independent and critical coverage. **The search was not exhaustive.**

## Inclusion, deduplication and conflicts

- **Included:** 39 rows (Apr 12–30: 4; May: 11; Jun: 7; Jul: 4; Aug: 3; Sep: 8; Oct 1–12: 2). Every row cites a URL fetched as raw text or queried by API (the GitHub advisory and release pages were read through `gh api`). No row relies on a search snippet alone.
- **Carried forward from the 2026-10-12 report:** 003-E01 → CI2026-003-006, 003-E02 → CI2026-003-023, 003-E03 → CI2026-003-031; all three dates re-confirmed against the pages.
- **Duplicate groups (one event, several documents):** `003-E02` (3.6 Flash card, changelog and launch post), `003-E03` (3.8 Flash card, changelog, launch post and Register), `003-gemini-cli-transition` (Google post and Register), `003-antigravity-2` (vendor post and the independent user report). Groups such as `003-model-lifecycle`, `003-gemma`, `003-robotics-er`, `003-cyber-models` link **separate** events that share a theme. They are not merged.
- **Conflicts recorded, not resolved:** GDPval-AA for 3.5 Flash is 1656 Elo in the 2026-05-19 launch post but 1349 (GDPVal-AA v2) in the 3.6 Flash card, a different benchmark version, and the card says its results are not comparable with earlier cards. Gemini 3.5 Pro was promised for "next month" on 2026-05-19, was still "testing with partners" on 2026-07-21, and was not found in the changelog through 2026-10-13. The Gemini CLI shutdown for individual tiers (2026-06-18) sits alongside continued weekly gemini-cli releases. These fit the paid-key exception, but the cutoff itself was not observed. Hugging Face repos were created before their announcements (Gemma 4 12B on 2026-05-23 for a 2026-06-03 post). Sitemap `lastmod` dates for the 3.6 and 3.8 Flash cards fall after their published dates, which points to unarchived revisions.
- **Figures confirmed against raw text** (text search of the saved pages or API JSON): AlphaEvolve 20% write amplification, 10.4% routing, ~9% storage footprint; 3.5 Flash 76.2% / 1656 / 83.6%; 3.6 Flash $1.50/$7.50 and 17%; 3.7 Flash $0.75/$3.75 through 2026-12-31 then $1.50/$7.50; 3.8 Flash $0.75/$3.75; Argon $2/$10, 1M output tokens, 77.9% DeepSWE, 300 TiB; Antigravity $20/$100/$200 (was $250) and 5X/20X; multi-agent call up to $10M with an 2026-08-08 deadline; Gemma 4 12B 16GB; DiffusionGemma 26B; EmbeddingGemma 2 740M; agentic video up to 88% / 66% / 7%; 950M+ Gemini app users and 900M+ Gemma downloads (vendor memo); CVSS 10.0 and patched versions 0.39.1 / 0.1.22; Register's Artificial Analysis 59 and $0.58 per task.
- **Not every number in the source pages was checked.** Only the figures above, which appear in ledger rows, were confirmed.
- **Untrusted-content note:** fetched pages were treated as data. No fetched page contained instructions directed at an AI agent or researcher. The Antigravity SDK post contains installation commands (`pip install google-antigravity`). These were not run.
