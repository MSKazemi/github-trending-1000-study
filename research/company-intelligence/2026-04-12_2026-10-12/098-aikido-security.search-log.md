# Aikido Security (098) — provisional source-query and inclusion log

> **PROVISIONAL, AI-ASSISTED, NOT HUMAN-REVIEWED (screened 2026-10-16).** Companion to the [report](098-aikido-security.md) and [event ledger](098-aikido-security.events.csv) for [#166](https://github.com/MSKazemi/github-trending-1000-study/issues/166). Provisional screen; the issue may be closed with this status recorded, and human factual/link, rights and methods review gates remain open.

**Window:** 2026-04-12…2026-10-12 inclusive (UTC dates). **Accessed:** 2026-10-16. **Method:** robots.txt checked for every host before fetching. Official pages were retrieved as raw HTML with `curl` using a generic `Mozilla/5.0` User-Agent. No personal identifier, email or credential was sent to any site. Text was extracted locally, and every number, version, date and quote used in a ledger row was confirmed with a regex search of the saved text. *Qualified 2026-10-16:* an independent spot-check found two limitation notes that this check missed (rows 025 and 035); see the report's spot-check section. Release dates and licences came from the GitHub REST API (`gh api`), the npm registry JSON, PyPI JSON, the Hugging Face model API, the NVD CVE and CVE-history APIs and GitHub's global advisory API. Independent coverage was discovered through the Hacker News Algolia API and three WebSearch queries. **This is not exhaustive retrieval.** Search-engine result totals were not exposed and are recorded as unknown, not zero. No page snapshots or hashes were archived in the repository, and pages may change after access.

## Inclusion, deduplication and conflicts

- **Included:** 37 rows (Apr 7, May 2, Jun 9, Jul 6, Aug 5, Sep 5, Oct 3). Every row cites a URL fetched as raw text or queried by API. No row relies on a search snippet alone.
- **Excluded by design:** about 43 "Top N tools", "alternatives" and "X vs Y" SEO listicles (marketing, no dated change), plus glossary/explainer posts. Malware disclosures without an independent check were kept as month-table context, not ledger rows, so the ledger does not amplify single-vendor threat claims.
- **Duplicate handling:** each row has its own group. The Root acquisition (017) and Aikido Libraries changelog (024) are linked in text. The Device Protection launch (003) and its platform expansions (011, 018, changelog #54) are linked in text. The safe-chain min-age exemption (033) is cross-referenced to changelog #56.
- **Date conflicts recorded, not resolved:** AI Code Audit appears in changelog #48 (2 Jun) before its launch post (16 Jun). The Android pentest appears in changelog #53 (12 Aug) before its blog (26 Aug). The OpenJS program launched 25 Sep (OpenJS) and Aikido posted 28 Sep. Several Aikido posts were edited after publication (e.g. the Code Audit post was updated 2026-08-05 and the benchmark post 2026-10-05), so the current text may differ from the text first published.
- **Figure conflicts:** keyv incident scope is about 11 packages in the original list versus "at least 444 packages" in the post's own 2026-08-05 update and "444+" in changelog #53 (an update, not a contradiction; corrected 2026-10-16). The keyv post's own per-package download figures are inconsistent (flat-cache 565M vs 580M/month). Changelog #57 says 6 languages in its title and 5 in its URL slug. Opengrep's "1.74 million binary downloads" (May) cannot be reconciled with the 11.97M release-asset total read on 2026-10-16 (different date, possibly different counting). CVE-2026-40175 carries 4.8 (CNA/NVD) and 8.1 (ADP) scores.
- **Unsupported claims screened out:** a "$70 million" Root price (search summary only) and "BleepingComputer independently verified" the JetBrains plugin code (search summary only, source inaccessible).
- **Figures confirmed against raw text** (regex search of saved page text): 70–80% / ~10x (Code Analysis); 15 plugins / seven accounts / ~70,000 installs (JetBrains, also in Infosecurity Magazine); 141 packages / 01:15–02:00 UTC / 918K (Mastra); 11.7 MB (SAP); 373 / 169 (May 12, context only); 25–74% / 2x / 1.74 million / 2,000+ / 10 companies (Opengrep); four million packages / under 8 minutes (Intel); 23/26 / 88.5% (Jul 16 benchmark); 11.7 billion tokens / 10 models / 32 vulns / 28 of 32 / $295 (Aug 21); 89 / 68 / 60 / 58 / $75 / $157 / $125 (Aug 24); ~2% (Betterleaks); 1.51 TB / 488 GB / 328 GB / 32.8% / 4-H200 / 504B (Altar); $37.6 million / 15 to 40 minutes (SiliconANGLE); $100,000 minimum (OpenJS); 235 / 4 / 36 findings / ~52 seconds (Audn); $1 per PR (Deep Review); 0.5.144 / over 100,000 (tensorlake). All remain **vendor or press statements**, not verified measurements.
- **Untrusted-content note:** fetched pages were treated as data. `help.aikido.dev/llms.txt` and the GitBook pages advertise machine-readable Markdown and an "AI Assistant" widget. The robots file carries a `Content-Signal: ai-train=yes, search=yes, ai-input=yes` line. These are site affordances, not instructions to this researcher, and nothing was executed from them. Aikido posts that comment on third-party AI incidents (e.g. claims about a jailbroken frontier model) were **not** used as evidence about those third parties. No page contained directives aimed at the researcher.
