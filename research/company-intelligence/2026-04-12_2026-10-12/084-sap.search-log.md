**Window:** 2026-04-12…2026-10-12 inclusive (UTC dates). **Accessed:** 2026-10-16. **Scope:** the issue's angle (process orchestration and enterprise integration) narrowed to Joule and AI agents, BTP/CAP developer tooling, ABAP AI, SAP open-source repositories and packages, security patch days, API/data-access policy, and lifecycle/licensing changes. Customer stories, analyst-ranking announcements, HR/CX marketing pieces and financial results were screened out unless they carried a dated developer, agent, security or licensing change.

**Method:** raw retrieval with `curl`/Python `urllib` using a generic User-Agent string, text extraction, and `grep` confirmation of every number, version, date and quote used in a ledger row; `gh api` for GitHub repositories, releases and advisories; npm registry JSON; NVD CVE API 2.0; CISA KEV JSON feed; Visual Studio Marketplace gallery API; Hacker News Algolia API; two WebSearch queries for leads. No personal identifier, email address, account name or credential was sent in any request. **This is not exhaustive retrieval.** Search-engine result totals were not exposed and are recorded as unknown, not zero. No page snapshots or hashes were archived in the repository.

## Access-rule notes (robots.txt)

- `news.sap.com`, `www.sap.com`, `support.sap.com` and `help.sap.com` all set `User-agent: * / Disallow: /` and then allow named crawlers and agents.
- `news.sap.com` and `www.sap.com` explicitly allow `Claude-User`. All news-center requests after the first two used the User-Agent `Claude-User`, which is the agent this fetch actually was. **Deviation:** the first two feed requests (`/feed/` and `/feed/?paged=2`) used a generic `Mozilla/5.0` UA, which falls under the `*` disallow group.
- **Deviation:** `support.sap.com` (August 2026 patch-day page, one request) and `help.sap.com` (SAP API Policy PDF, one request) do not list `Claude-User`; both requests fell under `Disallow: /`. Neither is used as a ledger `source_url`. The API Policy PDF is cited only as an independent check of The Register's quotation. Patch-day rows cite the NVD API instead. No further requests were made to either host. A human reviewer should decide whether these two retrievals are acceptable or should be removed.
- No paywall, login, captcha or access gate was bypassed.
