## 2. Verified company/product identity and baseline

Socket sells dependency supply-chain security: package-behaviour analysis and malware alerts, a GitHub App, CLI and SDKs, reachability analysis (Coana engine), **Socket Firewall** (install-time proxy/wrapper that blocks malicious packages; Free and Enterprise/registry modes), **Socket Patch** (applying security patches to dependencies), **Socket Basics** (SAST/secrets/container scanning wrapper), a browser extension, and an **MCP server** for AI assistants (hosted at `mcp.socket.dev`, OAuth sign-in per [docs](https://docs.socket.dev/docs/remote-socket-mcp)).

**Licensing is mixed and matters for reuse:** `socket-cli`, `socket-sdk-js`, `socket-sdk-python`, `socket-python-cli`, `socket-mcp` and `socket-patch` are MIT per the GitHub licence API; **`sfw-free` and `socket-basics` are PolyForm Shield 1.0.0** (source-available, not OSI open source; GitHub reports NOASSERTION); `socket-registry-firewall` and `firewall-release` have no detected licence; the `@coana-tech/cli` engine declares no licence on npm; `@socketsecurity/mcp` has no licence field on npm although its repository is MIT. The detection service, malware intelligence and dashboard are proprietary and hosted.

Pre-window baseline (context only): $40M Series B in October 2024 (per BankInfoSecurity); Socket CLI 2.0.0–2.1.0 were published on npm in Oct–Nov 2025 and are now deprecated as "bad build" while `latest` is 1.8.3; a January 2026 mass mis-flagging incident appeared only in a search snippet (E0, not read, not used).

## 8. One practical, falsifiable change for the maintainer's own repositories

**Repository/component:** [github-trending-1000-study](https://github.com/MSKazemi/github-trending-1000-study) CI and local dependency installation (Python standard-library-first; `python -m unittest discover -s tests -v`). Run as a **synthetic, network-limited** exercise. The disabled Trending `capture` command stays disabled.

**Candidate practice (not yet validated):** Reuse existing controls before adding any vendor tool. Arm A (control): current workflow plus GitHub Actions pinned to full commit SHAs and `pip install --require-hashes` from a hash-locked requirements file — no new service. Arm B: Arm A plus Socket Firewall Free (`sfw`) wrapping `pip`/`npm` installs in CI. Read the PolyForm Shield terms first; if the maintainer cannot accept them, Arm B is not run. Do not build a new firewall.

**Treatment/control and frozen comparable task:** Freeze 10 small synthetic dependency-change tasks (for example "add a pinned dev dependency", "bump a test-only package"), plus 3 planted **known-malicious package names taken from already-published public advisories**, installed only inside a disposable, network-restricted container with no credentials. A person other than the operator writes hidden acceptance checks. Accepted-task unit: a dependency change that passes the unit suite, keeps hashes and SHA pins valid, and is accepted by the human reviewer without rework.

**Success and guardrails:** Primary: accepted tasks / 10 (failed, blocked and abandoned included) and planted malicious installs blocked / 3 per arm. Guardrails: no real secrets, tokens or personal data anywhere in the environment; no planted package ever executes on a host with network egress; full unit suite green; no new runtime dependency added to the repository; no paid plan or API spend without approval. Measured human work: setup minutes, per-task review minutes, time spent on false blocks. Record the exact `sfw` version and any telemetry the wrapper sends. No energy or CO2e estimate unless metered. Commits stay authored by the maintainer; no AI contributor attribution.

**Stop/reversal rule:** Stop Arm B and keep Arm A if Arm B blocks no more planted packages than Arm A, adds more than 5 human minutes per task on average, produces any false block on a legitimate pinned dependency that costs over 15 minutes to clear, or its licence/telemetry terms cannot be confirmed. Stop immediately if any planted package executes. **No trial executed; no effect estimated.**
